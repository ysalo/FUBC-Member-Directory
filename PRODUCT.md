# Church Directory
<!-- impeccable:product-schema 1 -->

## Platform
ios

## Stack
User-selected native SwiftUI, Supabase authentication/database/storage. New implementation; no prototype client dependencies.

## Users
Approved church members find and contact people. Deacons coordinate visits and see responsibility-group birthdays. Pastors plan visits. Editors maintain member/group records; administrators manage account access. Administrative status does not grant private-visit access.

## Product Purpose
Keep contact information and care coordination accessible in a private, familiar iPhone application.

## Capabilities and Constraints
Directory, profiles, groups, birthdays, visits, private favorites/reminders, administration and account settings. English/Ukrainian. Unlisted distribution is intended, with approval enforced by the backend. Authentication, push and deletion need configured server services. No offline directory replication.

## Brand Commitments
The user explicitly requests an Apple-native application with SwiftUI and Impeccable. Familiar native navigation and controls are binding. No inherited prototype visual identity or assets.

## Operating Context
Assumption from migration brief: approximately 800 directory members, iPhone first. Used at home, church and while arranging visits; appearance follows device preference.

## Evidence on Hand
New product specification extracted from the prototype; consolidated schema is under audit. No usable Simulator screenshot evidence exists in this Windows workspace. AppSketch source remains unidentified.

## Open Decisions
Church ownership/contact/domain, sensitive-field policy, record retention, visit lifecycle changes and named timezone migration require confirmation before release.

## Accessibility & Inclusion
Dynamic Type, VoiceOver, semantic light/dark colors, English and Ukrainian, clear failure/empty states and accessible touch targets.
