# Asset provenance

`ios/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` was newly drawn for this implementation using original geometric lines (church roof, walls, doorway and cross). It is not AI raster generation, a stock image or a copied prototype asset. The matching vector construction is `.impeccable/app-icon-source.svg`. The 1024×1024 RGB PNG is opaque and was inspected directly; the icon requires device/home-screen review on Mac/iPhone before final approval.

No member photos or inherited illustration assets ship. Preview portraits use system SF Symbols.
